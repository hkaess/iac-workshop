# Trainer-Loesungen

Dieses Verzeichnis enthaelt Musterloesungen fuer alle Proxmox-Uebungen.

## Struktur

- `01-first-apply/`: erste deploybare Proxmox-VM aus einem Template
- `02-change-existing-vm/`: bestehende VM aendern und zweite Disk hinzufuegen
- `03-multiple-vms/`: eine moegliche Loesung fuer 5 VMs mit `for_each`
- `04-modules/`: Auslagerung in ein wiederverwendbares Proxmox-Modul

Jede Loesung enthaelt ausserdem:

- ein exemplarisches `workshop.auto.tfvars.example`
- kurze Kommentare im Code
- Erklaerhilfen fuer neue Terraform-Begriffe in [docs/terraform-concepts.md](../docs/terraform-concepts.md)
